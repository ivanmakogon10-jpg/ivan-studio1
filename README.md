# Иван Studio — исходники сайта

## Что где
- `src/` — рабочие исходники
  - `head.html` — meta-теги, шрифты, favicon
  - `body.html` — разметка страницы
  - `styles.css` — вся визуальная система (токены, светлая/тёмная тема, адаптив)
  - `data.js` — **всё редактируемое содержимое**: контакты, проекты, подход, услуги, калькулятор, шаги заявки
  - `app.js` — интерактив (курсор, тема, портфолио, кейсы, калькулятор, бриф)
- `standalone/` — готовый сайт: откройте `index.html` или залейте папку на хостинг
- `dist/` — сборка для публикации внутри Claude
- `build.py` — пересборка: `python3 build.py`

## Как добавить проект
Откройте `src/data.js`, добавьте объект в массив `PROJECTS`:

```js
{
  id: 'my-project',
  number: '04',
  title: 'Название',
  summary: 'Короткое описание.',
  categories: ['Web Design', 'Development'],
  status: 'released',
  cover: 'flow',            // 'arc' | 'menu' | 'flow' — генеративная обложка
  image: 'img/my.jpg',      // или путь к реальному изображению (перекрывает cover)
  span: { col: 'span 4', ratio: '4 / 3' },
  case: { role: ['Дизайн'], task: '', solution: '', stack: [], process: [] }
}
```
Пустые поля `case` показываются как «Раздел в подготовке» — заполните, и они появятся в кейсе.
Концептуальные проекты — массив `CONCEPTS` в том же файле.

## Как поменять контакты
Один объект `CONTACTS` в начале `src/data.js` — ссылки, `mailto:` и `tel:` подставляются автоматически везде.

## Как подключить приём заявок
В конце `src/data.js`:
- `BRIEF_ENDPOINT = 'https://ваш-webhook'` — заявка уйдёт POST-запросом (JSON), либо
- `TELEGRAM_BOT = { token: '...', chatId: '...' }` — придёт в Telegram.

Пока ничего не задано, заявки пишутся в `localStorage` (ключ `ivan-briefs`) и в консоль — ничего не теряется.
Токен бота в открытом коде виден всем: для продакшена лучше вебхук на своём сервере.

## Цены
`SERVICES` — карточки услуг, `CALC` — коэффициенты калькулятора (базы, множители, надбавки).
